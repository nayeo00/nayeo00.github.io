=====================================================
AI Content Portfolio — 사용 설명서
=====================================================

이 폴더를 GitHub 저장소에 그대로 올리고 GitHub Pages를
켜면 바로 작동하는 정적 사이트입니다.
빌드 과정, 설치, 서버 없이 폴더째로 업로드하면 끝입니다.


-----------------------------------------------------
1. 영상 주소 바꾸기
-----------------------------------------------------
index.html 파일을 열고 아래 세 줄의 주석을 검색하세요.

  <!-- 잘 먹겠습니다 YouTube URL -->
  <!-- 잘마침 YouTube URL -->
  <!-- 컨디션 레이디 YouTube URL -->

각 주석 바로 아래에 있는 <iframe src="..."> 부분의
유튜브 주소만 바꾸면 됩니다.

예)
  src="https://www.youtube.com/embed/영상ID"

유튜브 영상 페이지 주소가
  https://youtube.com/shorts/Ufk-H6Cy57E
  https://youtu.be/Tlt4L4lYqGQ
같은 형태라면, 뒤에 붙은 영상 ID(Ufk-H6Cy57E, Tlt4L4lYqGQ 등)만
아래 형태로 바꿔 넣으면 됩니다.
  https://www.youtube.com/embed/영상ID


-----------------------------------------------------
2. CHRONOS 이미지 바꾸기
-----------------------------------------------------
images/chronos/ 폴더 안에 있는 8개 파일과
"동일한 파일명"으로 새 이미지를 덮어씌우면 됩니다.

  01-product-bottle.jpg        제품(향수병)
  02-store-exterior.jpg        매장 외관
  03-store-interior.jpg        매장 인테리어
  04-package-bags.jpg          쇼핑백
  05-package-box.jpg           패키지 박스
  06-campaign-azure-spark.jpg  광고 비주얼
  07-web-ui.jpg                웹 UI

이미지를 통째로 늘리거나 줄이고 싶으면
index.html에서 <div class="gallery"> 안의
<figure> 블록을 복사/삭제해서 개수를 조절하면 됩니다.


-----------------------------------------------------
3. CHRONOS PDF 넣기
-----------------------------------------------------
pdf 폴더 안에 있는 안내 파일을 지우고,
브랜드북 PDF 파일을 아래 이름으로 넣어주세요.

  pdf/chronos-brandbook.pdf

이름을 다르게 하고 싶다면 index.html에서
href="pdf/chronos-brandbook.pdf" 부분도 같이 바꿔주세요.


-----------------------------------------------------
4. 문구 수정하기
-----------------------------------------------------
index.html을 열고 바꾸고 싶은 제목이나 문장을
그대로 검색해서 수정하면 됩니다.
(예: "잘 먹겠습니다", "혼자 늙는 시대를 배경으로" 등)


-----------------------------------------------------
5. 색상 수정하기
-----------------------------------------------------
css/style.css 파일 맨 위 :root { ... } 안에
색상 변수들이 모여 있습니다. 그 값만 바꾸면
사이트 전체 색상이 한 번에 바뀝니다.

  --brass   : 브라스 골드 포인트
  --signal  : 청록 포인트
  --neutral : 뮤트 톤 (잘마침 섹션)
  --bg      : 기본 배경색


-----------------------------------------------------
6. 연락처 추가하기 (선택)
-----------------------------------------------------
index.html 맨 아래쪽 <footer> 안에 주석으로
이메일 예시가 남겨져 있습니다. 그 줄의 주석(<!-- -->)을
지우고 이메일 주소를 바꿔 넣으면 푸터에 표시됩니다.


-----------------------------------------------------
7. GitHub Pages에 올리기
-----------------------------------------------------
1) GitHub에서 새 저장소를 만듭니다.
2) 이 폴더 안의 모든 파일/폴더를 그대로 저장소에 업로드합니다.
   (portfolio 폴더 자체가 아니라, 폴더 "안의 내용물"을 올리세요)
3) 저장소의 Settings → Pages 메뉴로 이동합니다.
4) Branch를 main(또는 master), 폴더를 / (root)로 설정 후 저장합니다.
5) 잠시 후 발급되는 주소가 최종 포트폴리오 링크입니다.
